# Features — CineScope

## Verified in the iOS 26 simulator

- Two-tab interface: Discover and Watchlist.
- Search bar with debounced movie queries and initial results.
- Responsive poster grid using programmatic Auto Layout.
- Detail screen with large poster, title, year, genre, rating and synopsis.
- Add/remove watchlist button reflected immediately in the detail screen.
- Watchlist tab with saved movies and swipe-to-delete.
- Optional App Store deep link.
- Loading spinner, empty state and error message.
- Adaptive light and dark styling.

## Verification note

Unit and UI tests are authored and compile, but execution was skipped at the user's request.

## Physical-device checks

App Store deep links and external network behaviour should be confirmed on a physical iPhone.
